🔒 HTTPS 보안 주소로 이동하기 🚀
🤖 안드로이드 크롬 '선택/터치 안 됨' 해제 순서
[원인] 스마트폰 설정에서 Chrome 앱 자체의 알림 권한이 비활성화되어 브라우저 내 선택이 잠긴 상태입니다.

[해결 3단계]
  1. 스마트폰 설정(⚙️) ➔ 애플리케이션 ➔ Chrome 선택
  2. '알림' 메뉴 클릭 ➔ '알림 허용' (파란 스위치 켜기)
  3. 크롬 앱으로 돌아와 주소창 좌측 🔒(자물쇠) ➔ 권한 ➔ 알림 '허용'으로 변경!
🍎 아이폰 (iOS Safari) 차단 해제 법

iPhone Safari 브라우저 탭에서는 알림이 기본 차단됩니다.
Safari 하단 공유 버튼(📤) ➔ '홈 화면에 추가'를 눌러 모바일 앱으로 설치(PWA)한 뒤 실행해 주세요!
